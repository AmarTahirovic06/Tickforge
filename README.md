Tickforge is a a hardware market data engine for NASDAQ ITCH 5.0, targeting a Xilinx Atrix-7 FPGA. Currently parsing trade messages off the wire, it maintains per-symbol streaming statistics in block RAM, and emits an order packet. It is measured, reproducible, with the wire-to-wire latency being the focal point. 
Current status is Phase 1, simulation. A byte-serial framer and message type dispatch are implemented in SystemVerilog and verified with cocotb + Verilator against hand-built ITCH streams. The Python Golden Model is in pure integer arithmetic, validated against a 2026 ITCH file. The model itself serves as a bit-exact oracle for later phases.
